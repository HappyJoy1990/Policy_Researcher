# 政策研究报告大纲（人类可读部分）

> 与 `final_report.json` 同时交付。全文须明确区分：**已核实事实** / **基于 A 组的判断** / **基于 B 组的趋势参考** / **测算假设**。

## 1. 执行摘要
- 研究对象、主区域（`regions.primary`）、扩展区域、时间窗
- 3-5 条核心结论（每条标注证据组别与置信度）
- 最需要立刻做的 3 件事（来自 `action_items`）

## 2. 研究范围与口径
- 主体核验结果（企业全称、统一社会信用代码、注册地址、来源 URL）或「行业输入，未绑定企业主体」
- S1-Sn 赛道边界与关键词
- 研究问题、时间窗、`metrics_dictionary` 指标口径表

## 3. 政策全景与 A/B 证据
- A 组（直接适用）政策清单表：名称 / 发文机关 / 效力层级 / 生效状态 / 赛道标签 / PESTEL / 证据分级 / 来源
- B 组（间接参考）政策清单表：额外列出来源省市与「仅为趋势参考」标注
- 全国高相关数量、主区域官方平台尝试清单；无地方文件时写明基准情景回退

## 4. 政策沿革与版本比对
- 时间轴：发布 → 修订 → 废止 → 接力
- 逐版变化要点（力度、门槛、覆盖范围、时限）
- 连续性与转向信号、政策空档期

## 5. 区域横向对比矩阵
- 维度 × 区域表格：支持力度 / 适用门槛 / 补贴额度 / 覆盖赛道 / 生效时序 / 申报窗口
- 每格标注政策 id；无核实文件的区域如实标注

## 6. 量化影响评估
- 测算口径与公式、基准值
- 乐观 / 基准 / 悲观三情景测算表
- 敏感性分析与假设清单（含来源类型与局限）

## 7. 机会风险与六层逻辑推演
- 机会风险清单（≥8 条、赛道覆盖率、B 组引用占比）
- 关键政策的 L1→L6 传导链，逐层传导变量与置信度
- PESTEL 定位（含历史稳定性）、多源流分析（政治流结合主区域）

## 8. 三情景与关键不确定性
- 触发条件逐条标注 A/B 证据组别
- 关键不确定性：是否可由主区域文件解决、需补什么证据

## 9. 申报落地行动清单
- 动作 / 条件 / 材料 / 责任部门 / 时间窗口 / 状态 / 前置依赖
- 「待核实」项单独列出并给出核实路径

## 10. 证据附录
- 全部 `source_url` 官方详情页清单（按政策 id 排序）
- 关键 `evidence_quote` 原文摘录

## 11. 局限声明
- 未核实事项、B 组证据的使用边界、测算假设、地方配套细则缺口
- 契约校验结果与 `validation.checked_at`
